# Mockup Maker

Upload a company logo and see it engraved on Cutco knives in seconds. Runs entirely in the browser — nothing is uploaded anywhere.

- Works on iPhone, iPad and desktop. Add it to the home screen to use it like an app; it works offline once loaded.
- Products: Spatula Spreader, Santoku, 6" Veggie Knife, Santoku Trimmer — each in Classic, Red and White handles.
- Branding only, or Personalized (logo side + recipient side in Georgia Bold Italic).
- Logo cleanup: remove colors, cleanup level, light-logo mode, separate touching colors, combine two logos.
- Download or Share each mockup, or share all four at once.

Knife photos are Cutco product photography; this is a sales-presentation aid, not an engraving proof.
